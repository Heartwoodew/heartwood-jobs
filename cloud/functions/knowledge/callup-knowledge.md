# CallUp helper knowledge (placeholder)

This is not the source-verified pack. That pack is `docs/knowledge/callup-knowledge.md`, produced separately. It is not in this branch yet. Do not invent CallUp steps that are not written here.

## What Helper can do

Helper only looks things up. It cannot create a job, change a job, send a message, send an email, or send anything to Xero.

## Who sees which jobs

An operator sees jobs assigned to them. Prices stay off that login.
A supervisor or admin sees prices only when their profile already allows it.
One business never sees another business's jobs.

## If you are unsure

If a fact is not in these notes or in the job data, say you don't have it. Safety advice, dates, quantities and permissions must be repeated plainly.
